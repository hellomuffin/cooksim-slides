CookSim - presentation clips

Presentation-ready clips in three groups. Every clip is a side-by-side composite: top-down left, first-person right, both rendered from the same state each tick. A machine-readable index of every clip lives at manifest.json - see README for the download pattern.

A clean, successful run of the common cheeseburger recipe on the medium map, filmed end to end. The cook executes the stored ground-truth plan with no injected error, no assistant and no dialogue.
